Clear information about local storage and the technologies used by grimoni.com.

C

Last updated: September 21, 2026. The current version of grimoni.com does not set cookies or use web storage.

1. Current configuration

The website does not set cookies or write information to localStorage or sessionStorage. It does not include advertising, tracking profiles, embedded videos, external maps, login features or consent tools. Fonts are hosted on the same server and do not require connections to Google Fonts or other external font providers.

2. Cloudflare performance measurement

The website uses Cloudflare Web Analytics / Real User Monitoring (RUM). This service loads a technical beacon in the browser and sends Cloudflare performance and usage metrics for the page, such as loading times and Core Web Vitals. Its purpose is to diagnose, protect and improve the website’s availability and performance.

Cloudflare states that its RUM beacon neither accesses nor writes cookies, localStorage, sessionStorage, IndexedDB or other data stored on the device. However, it is a performance analytics technology and should not be confused with the website’s own technical server logs.

3. Technical server logs

The server may generate technical access logs containing the IP address, date and time, requested resource, browser and response code. These logs are not cookies: they are used to operate, diagnose and protect the service. Their processing is explained in the Privacy Policy.

4. Necessary cookies and consent

Because the current configuration does not use cookies, no consent banner is displayed. If strictly necessary cookies are introduced in the future, they will be documented here. Any analytics, advertising or non-essential cookie will remain disabled until the user can accept, reject or configure it through an affirmative action.

5. How to check or delete cookies

You can review and delete cookies using your browser’s privacy tools. Deleting or blocking cookies does not currently affect this website’s operation because no feature depends on cookies.

6. Changes

This policy will be reviewed before introducing any technology that sets cookies, accesses device storage or materially changes the current measurement. The date of the current version will appear at the top.

7. Contact

For any questions about this policy, email info@grimoni.com.
