Regles aplicables a l’accés i l’ús de grimoni.com com a lloc web corporatiu informatiu.

T

Darrera actualització: 21 de setembre de 2026. Aquestes condicions regulen el lloc web, no els projectes o serveis professionals contractats amb Grimoni.

1. Titular i abast

El lloc web pertany a GRIMONI, SLU. Les seves dades identificatives completes consten a l’ Avís legal. La navegació no requereix registre i no crea per si sola una relació contractual de consultoria.

2. Caràcter informatiu

Els continguts descriuen capacitats, enfocaments i possibles aplicacions d’intel·ligència artificial i automatització. Cada projecte depèn de les dades, els sistemes, els riscos, els permisos, els requisits i els objectius del client. Cap explicació del lloc web constitueix una promesa automàtica de viabilitat o de resultat.

3. Contractació professional

Les consultes enviades per correu no impliquen l’acceptació d’un encàrrec. Els serveis es regiran exclusivament per la proposta, ordre de treball o contracte acceptat per les parts, que establirà l’abast, els lliurables, el preu, el calendari, la propietat intel·lectual, la confidencialitat, els nivells de servei i el tractament de dades.

4. Ús permès

Pots consultar el lloc web i compartir enllaços a les seves pàgines. No està permès interferir en el seu funcionament, accedir-hi sense autorització, fer proves de seguretat no consentides, distribuir codi nociu, extreure continguts de manera abusiva o utilitzar materials de Grimoni infringint drets de propietat intel·lectual.

5. Propietat intel·lectual

Els continguts, la identitat visual, les marques, el codi i els materials propis estan protegits per la normativa aplicable. L’accés al lloc web no concedeix llicències d’explotació, excepte per a la visualització ordinària i els usos legalment permesos.

6. Disponibilitat i responsabilitat

Grimoni pot actualitzar, suspendre o modificar el lloc web per mantenir-lo, corregir errors o adaptar-ne els continguts. Dins dels límits permesos per la llei, no respon d’interrupcions inevitables, usos contraris a aquestes condicions o decisions preses exclusivament a partir d’informació general del lloc web.

7. Privacitat

El tractament de dades personals es regeix per la Política de privacitat. La configuració actual de l’emmagatzematge local es descriu a la Política de galetes.

8. Legislació aplicable

Aquestes condicions es regeixen per la legislació del Principat d’Andorra. Llevat que una norma imperativa disposi el contrari, les controvèrsies relacionades amb l’ús del lloc web se sotmetran als tribunals andorrans.

9. Contacte

Per a preguntes sobre aquestes condicions, escriu a info@grimoni.com.
